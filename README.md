# Salesventory

![Salesventory logo](assets/salesventory-logo.png)

**Salesventory** is a cloud-based business management and inventory SaaS for small and medium businesses. It brings sales, inventory, customers, expenses, suppliers, staff, reports, recurring work and business insights into one workspace.

This repository contains the production application, Supabase migrations, protected API services, deployment configuration and automated verification workflows.

## Production release discipline

Customer releases are validated against staging and promoted to `main` only after production-readiness gates pass.
