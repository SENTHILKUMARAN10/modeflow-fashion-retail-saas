# Thatha Kadai

Complete owner-side billing, stock, customer, expense and invoice management system.

## Live website

https://thatha-kadai-billing.senthilkumaran539.chatgpt.site

## Source code

Download `thatha-kadai-source.zip`, extract it, then run `npm run install:ci` and `npm run dev`.

The production PIN is stored securely in the hosting environment and is not included in this repository.
